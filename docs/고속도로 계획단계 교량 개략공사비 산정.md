## 1. 개략공사비 산정 체계 및 AI 에이전트 연산 규칙

### 1.1 총공사비 구성 체계

고속도로 교량 및 도로 구조물의 계획단계 개략공사비는 다음과 같은 적산 계층 구조를 갖는다.

```
총공사비 (Total Construction Cost)
 ├── 직접공사비 (Direct Construction Cost)
 │    ├── 상부공 (Superstructure)
 │    ├── 하부공 (Substructure: 교대 + 교각)
 │    ├── 기초공 (Foundation: 말뚝기초 / 직접기초 / 매스기초)
 │    ├── 부대공 (Ancillary Works: 옹벽, 가시설, 가도/가교, 이설도로, 배수시설 등)
 │    └── 토공 (Earthwork: 터파기, 깎기/절토, 쌓기/성토)
 ├── 기타공사비 (Miscellaneous Cost)
 │    └── 직접공사비의 10% (0.10 × 직접공사비)
 └── 제잡비 및 간접비 (Indirect Costs, Overhead & Profit, Tax)
      └── 직접공사비(또는 순공사비)의 40.0% ~ 43.9% 일괄 반영 (발주처/설계기준별 적용)

```

### 1.2 핵심 연산 공식 (Calculation Formulas)

1. **상부공 직접공사비 (**$C_{super}$**)**
   

   $$
   C_{super} = \text{교량 연장}(L, \text{m}) \times \text{상부 폭원}(B, \text{m}) \times \text{형식/경간장별 } m^2 \text{당 단가}(\text{원}/m^2)
   $$

   
   *경간 구성이 복합 형식인 경우, 각 경간별 면적과 해당 형식 단가를 개별 곱하여 합산한다.*

2. **교대공 직접공사비 (**$C_{abut}$**)**
   

   $$
   C_{abut} = \sum_{i=1}^{N_{abut}} \left[ \text{교대 높이별 단위폭당 단가}(\text{원}/\text{m}) \times \text{상부 폭원}(B, \text{m}) \right]
   $$

   
   *교대는 통상 양 시/종점 2개소(A1, A2)가 기본이며, 직접기초 단가 기준 적용 후 말뚝기초 적용 시 말뚝 공사비를 추가한다.*

3. **교각공 직접공사비 (**$C_{pier}$**)**
   

   $$
   C_{pier} = \sum_{j=1}^{N_{pier}} \text{교각 형식/직경/높이별 기당 단가}(\text{원/기})
   $$

   
   *규격표에 명시되지 않은 높이는 동일 단면 규격 내에서 인접 구간 증분(Slope)을 활용하여 선형보간(Linear Interpolation)한다.*

4. **기초공(강관말뚝) 직접공사비 (**$C_{pile}$**)**
   

   $$
   C_{pile} = \sum (\text{말뚝 본수} \times \text{말뚝 길이}(L_{pile}, \text{m})) \times \text{공법별 단위 단가}(\text{원}/\text{m})
   $$

   
   *직접항타(215,000원/m), SIP(233,000원/m), SDA(245,000원/m), PRD(341,000원/m)*

5. **부대공 및 토공 직접공사비 (**$C_{ancillary}$**)**

   * 보강토옹벽: 연장(m) × 평균높이(m) × $m^2$당 단가 또는 높이별 m당 단가

   * 가시설(토류판 등): 기당 55,000,000원 (또는 면적당 200,000원/$m^2$)

   * 우회도로 / 군도이설: 연장(m) × 850,000원/m

   * 터파기 / 성토 / 절토: 체적($m^3$) × 단위단가($원/m^3$)

6. **총공사비 집계 (**$C_{total}$**)**
   

   $$
   C_{direct} = C_{super} + C_{abut} + C_{pier} + C_{pile} + C_{ancillary} + C_{earth}
   $$

   $$
   C_{misc} = C_{direct} \times 0.10
   $$

   $$
   C_{total} = C_{direct} \times (1 + \text{제잡비율}) \quad (\text{제잡비율: 40.0\% ~ 43.9\%})
   $$

1. **M.S.S 공법 교량 연장 보정**:

   * 기준 연장: $L_0 = 700\text{m}$ ($900,000 \sim 992,200\text{원}/m^2$)

   * 연장 100m 증가 시: 공사비 7% 감액 (예: 800m 적용 시 $900,000 \times 0.93 = 837,000\text{원}/m^2$)

   * 연장 100m 축소 시: 공사비 7% 증액 (예: 600m 적용 시 $900,000 \times 1.07 = 963,000\text{원}/m^2$)

2. **F.S.M 공법 교량 연장 및 교고 보정**:

   * 기준 조건: 연장 $L \ge 500\text{m}$, 교각 높이 $H \approx 10\text{m}$ 내외

   * 연장 300m 이하이거나 교고가 높은 교량(H > 15m)은 동바리 가설비 증가에 따라 반드시 단가를 상향 보정한다.

### 2.4 강재 가격 변동에 따른 강상부 공사비 보정 메커니즘

강합성 거더 및 STEEL BOX 계열은 원자재 가격 변동에 매우 민감하다. 다음 공식으로 기준시점 대비 공사비를 보정한다.

```
조정 상부단가 = 기본 상부단가 + (현재 강판단가 - 기준 강판단가) × 단위면적당 강재 투입비율

```

* **강재비 비중**: 강상부 직접공사비 중 강재 재료비 비중은 약 **35% (0.35)** 로 산정

* **실적 변동 예시 (ST. BOX 60m 연속경간 기준)**:

  * 2021년 01월 (기준 강재단가 66\~77만 원/톤): 상부단가 1,441,000원/$m^2$ (순수 강재비 504,350원)

  * 2021년 07월 (급등기 강재단가 130만 원/톤): 상부단가 1,743,610원/$m^2$ (강재비 806,960원 반영, +21.0% 상승)

  * 2021년 09월 (최고점 강재단가 131만 원/톤): 상부단가 1,794,045원/$m^2$ (강재비 857,395원 반영, +24.5% 상승)

  * 80m급 강박스교(기본 1,841,000원/$m^2$): 강재단가 130만 원 반영 시 2,227,610원/$m^2$로 보정

### 7.2 산정 파이프라인 의사코드 (Execution Pseudo-Code)

```
def calculate_bridge_cost(input_data):
    # 1. 상부공 산정
    super_cost = 0
    for span in input_data['spans']:
        area = span['span_length'] * input_data['bridge_width']
        unit_cost = lookup_superstructure_cost(span['type'], span['span_length'])
        super_cost += area * unit_cost

    # 2. 교대공 산정
    abut_cost = 0
    for abut in input_data['abutments']:
        unit_cost_width = lookup_abutment_cost(abut['height'], input_data['spans'][0]['type'])
        abut_cost += unit_cost_width * input_data['bridge_width']

    # 3. 교각공 산정
    pier_cost = 0
    for pier in input_data['piers']:
        pier_unit = lookup_pier_cost(pier['type'], pier['diameter'], pier['height'])
        # 왕복 4차로 이상 광폭 교량일 경우 폭원 계수 반영 (통상 1.8~2.0 배)
        width_factor = 2.0 if input_data['bridge_width'] >= 24.0 else 1.0
        pier_cost += pier_unit * width_factor

    # 4. 기초공 (말뚝기초) 산정
    pile_unit_price = {'DIRECT': 215000, 'SIP': 233000, 'SDA': 245000, 'PRD': 341000}[input_data['pile_method']]
    total_pile_length = 0
    for abut in input_data['abutments']:
        if abut['foundation'] == 'PILE':
            total_pile_length += abut['pile_len'] * abut['pile_count']
    for pier in input_data['piers']:
        if pier['foundation'] == 'PILE':
            total_pile_length += pier['pile_len'] * pier['pile_count']
    foundation_cost = total_pile_length * pile_unit_price

    # 5. 가시설 및 부대공 산정
    num_piers = len(input_data['piers'])
    temp_facility_cost = num_piers * 55000000  # 가시설 기당 5,500만 원
    ancillary_cost = temp_facility_cost

    # 6. 직접공사비 및 총공사비 집계
    direct_cost = super_cost + abut_cost + pier_cost + foundation_cost + ancillary_cost
    misc_cost = direct_cost * 0.10  # 기타공사비 10%
    total_cost = direct_cost * (1 + input_data['markup_rate'])  # 제잡비 40% 적용
    unit_cost_m2 = total_cost / (input_data['bridge_length'] * input_data['bridge_width'])

    return {
        'direct_cost': direct_cost,
        'misc_cost': misc_cost,
        'total_cost': total_cost,
        'unit_cost_m2': unit_cost_m2
    }

```

## 8. 요약 및 실무 적용 시 주의사항

1. **지반 조건별 기초 형식 검토**:

   * 지지층(풍화암/연암) 심도가 10m 이내로 얕은 경우 직접기초가 경제적이나, 하천 세굴 우려가 있거나 연약지반인 경우 반드시 SDA/PRD 현장타설말뚝 또는 강관말뚝($D508$)을 반영해야 한다.

2. **곡선반경 및 사각(Skew) 할증**:

   * 교량에 사각($\theta$)이 있는 경우 교대 및 교각 폭원이 $1/\cos\theta$ 로 증가하므로 하부공 단가에 면적 증가분을 곱해야 한다.

   * 사각이 $20^\circ$ 이상인 경우 강합성 또는 빔 배치 간격 보정으로 상부공 약 3\~5% 할증을 고려한다.

3. **물가변동(ESC) 및 물가지수 보정**:

   * 본 자료의 단가는 2015\~2021년 기준 실적을 바탕으로 표준화한 값이므로, 현 시점(2026년 기준 등) 적용 시 한국건설기술연구원 발표 **건설공사비지수(교량부문)** 또는 생산자물가지수를 연동하여 물가상승분을 보정 적용해야 한다.
