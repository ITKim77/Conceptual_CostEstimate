# /verify-benchmarks 커맨드 실행 프로토콜

1. `quality-verifier` 에이전트를 호출합니다.
2. `docs/고속도로 계획단계 교량 개략공사비 산정.md` 6장에 기술된 벤치마크 케이스들을 테스트 하네스에 주입합니다:
   - Case 1: 연축교 고가차도 (원안 및 비교1~5안)
   - Case 2: 안동JCT교 (비교1~3안)
3. 적산 결과와 실적 데이터의 단가, 직접공사비, 총공사비 오차율을 계산합니다.
4. 모든 항목에서 오차가 0% (반올림 오차 이내)일 경우 `PASS`, 아닐 경우 `FAIL` 및 불일치 항목 상세 리포트를 출력합니다.
